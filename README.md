# Оформление билетов

Тестовое задание Sqoch: покупка билетов на мероприятие на моковых данных. React, TypeScript, Zustand для состояния, CSS modules для стилей. Бэкенда нет, сервер имитирует один файл.

Демо: https://mitkinstan.github.io/tickets-test/

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на http://localhost:5173. Нужен Node 20.19+ или 22.12+.

Ещё есть `npm run typecheck`, `npm run lint` и `npm run build`.

В `.npmrc` включён `legacy-peer-deps`. Без него `npm install` на npm 10.8 падает с ошибкой про `edgesOut`.

## Как это работает

1. Участники. От 1 до 4 человек, у каждого имя и возраст. Email один на весь заказ. Под формой сразу виден итог.
2. Проверка. Показан состав заказа с ценой каждого билета и email. Если что-то не так, можно вернуться и поправить, введённое не пропадёт.
3. Подтверждение. Мок-сервер ещё раз проверяет, остались ли места. Если да, показывается номер заказа. Если нет, экран «Места закончились» с числом свободных мест и кнопкой возврата к заказу.

## Правила

- Полный билет стоит 2000 ₽ с 14 лет, детский 1000 ₽ для тех, кому нет 14.
- Ребёнок младше 14 лет проходит только вместе с участником от 18 лет в том же заказе.
- Подросток 14-17 лет платит как взрослый, но сопровождающим ребёнка не считается. В задании написано «от 18 лет», я понял это буквально.
- Возраст это целое число от 0 до 120.
- Ошибка у поля появляется, когда из него ушли, или после нажатия «Продолжить».

## Как показать «места закончились»

Внизу формы есть сворачиваемая демо-панель. Галка «Места закончатся перед подтверждением» сработает один раз при следующем подтверждении заказа. Ещё там можно задать число свободных мест (по умолчанию 10), например поставить 1 и заказать билеты на двоих.

Сценарий для проверки:

1. Взрослый и ребёнок, email, «Продолжить», «Подтвердить заказ». Заказ оформлен.
2. «Оформить новый заказ», включить галку в демо-панели и подтвердить. Появится экран «Места закончились».
3. «Изменить заказ». Введённые данные на месте.
4. Один ребёнок без взрослого. Форма не пропустит и объяснит почему.

## Устройство проекта

- `src/domain`: цены, типы и валидация. Чистые функции, ничего не знают про React.
- `src/api/mockApi.ts`: фальшивый сервер. `confirmOrder` ждёт около секунды и возвращает либо `ok` с заказом, либо `soldOut` с числом оставшихся мест. Исключений для обычного случая «мест нет» нет.
- `src/store/checkoutStore.ts`: Zustand-стор. Хранит шаг, данные формы и результат. Тексты ошибок и итог в сторе не лежат, они считаются из данных при каждом рендере.
- `src/components`: экраны и их стили.

Вёрстка рассчитана на 360 px: одна колонка, шрифт в полях 16 px (чтобы iOS не увеличивал страницу), кнопки не ниже 44 px.
